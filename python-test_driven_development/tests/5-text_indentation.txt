==================================
How to use 5-text_indentation.py
==================================

This module defines a function ``text_indentation(text)``.

Usage
=====

Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Formatting text with special characters:
    >>> text_indentation("Hello. How are you? Fine: thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks.
    <BLANKLINE>

Trimming leading spaces after delimiters:
    >>> text_indentation("   Hello world.   Next sentence?   Done.")
    Hello world.
    <BLANKLINE>
    Next sentence?
    <BLANKLINE>
    Done.
    <BLANKLINE>
